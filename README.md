\# K-12 SOC \& Cyber Operations Playbooks 🛡️



Welcome to the K-12 SOC Playbooks repository. Defending school district infrastructure requires speed, automation, and doing more with less. 



This repository contains field-tested scripts, threat-hunting queries, and incident response runbooks designed specifically for K-12 environments using tools like \*\*runZero, Wazuh, and CrowdStrike\*\*.



\## What's Inside

\* \*\*`/docs`\*\*: AI SOC Advisor deployment guides, architecture concepts, and Proof of Concepts (like the Sentinel-X Gemini/NotebookLM build).

\* \*\*`/runbooks`\*\*: Step-by-step containment guides for IoT, network hardware, and endpoints.

\* \*\*`/scripts`\*\*: Automation to parse telemetry and speed up time-to-remediation.

\* \*\*`/queries`\*\*: Asset and vulnerability hunting queries.

\* \*\*`/wazuh`\*\*: Custom rules and decoders optimized for the K-12 threat landscape.



\## Mission

To stop re-inventing the wheel. By sharing our workflows, K-12 IT and Security teams can pivot from reactive firefighting to proactive threat hunting. Feel free to fork, adapt, and submit pull requests.
